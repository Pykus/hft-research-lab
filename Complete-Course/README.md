# HFT C++20 Complete Course

A practical, incremental course built around the **real source code** in this repository. Each lesson combines a short explanation, concise notes, and hands-on exercises. All examples target Ubuntu/WSL2, GCC, CMake, and GDB in VS Code.

## Learning workflow

1. Read the lesson (10–15 minutes).
2. Inspect the referenced real source files.
3. Predict the result **before** running code.
4. Do the exercises and run the tests.
5. Restore a clean working tree or commit your solution to a separate branch.

The course is educational. It is not a production trading system. The source code in `src/`, `include/`, and `tests/` is the single source of truth; lesson snippets are illustrative and may be abbreviated.
